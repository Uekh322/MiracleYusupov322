# Чудо Обувь

WPF, .NET Framework 4.7.2, Entity Framework 6.2, SQL Server LocalDB.

Открыть `YusupovMiracle.sln` или существующий `YusupovMiracle.slnx` в Visual Studio и запустить проект YusupovMiracle.
Подключение задано в `YusupovMiracle/App.config`: `(localdb)\MSSQLLocalDB`, база `YusupovMiracleShow`, проверка подлинности Windows.

Сохранён подход Yusupov41: EDMX и классы таблиц, статический GetContext(), Manager.MainFrame, страницы с обработчиками событий, UpdateServices(), LINQ и ListView с DataTemplate. Дополнительные свойства расположены непосредственно в классах Client, Product, CommodityPosition, OrderItem и Order. GetContext добавлен также в T4-шаблон, чтобы не исчезать после обновления модели.

Вход только по логину. Права определяются таблицей UserRole: 1 — администратор, 2 — пользователь, 3 — менеджер. Гость просматривает каталог с поиском, фильтрацией и сортировкой; пользователь оформляет заказ; менеджер также просматривает, добавляет и удаляет заказы; администратор дополнительно редактирует существующие заказы.

В каталоге доступны поиск по названию, фильтры категории и производителя, сортировка по цене. Остаток модели — сумма QuantityInStock по её товарным позициям. При остатке до трёх пар включительно карточка окрашивается в #ff8080. Заказываются конкретные модель и размер. Сумма строки — Quantity × PriceAtOrderTime, сумма заказа — сумма строк. Стоимость пары фиксируется при добавлении в заказ.

Номера записей присваивает SQL Server (IDENTITY). При сохранении в одной транзакции записываются заказ, строки и изменения остатков; при редактировании учитывается разница количества, при удалении товары возвращаются на склад. Перед записью БД повторно проверяет наличие товара. Отмена окна не меняет данные в базе.

Из архива взяты логотип, иконка, заглушка изображения и 31 фотография. Используются Calibri, белый фон, #D2F6E7 и #70B2AF.

Юнит-тестов, тестовых проектов и зависимостей MSTest в решении нет.
